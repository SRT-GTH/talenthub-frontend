## Fonts

Every family the frames use is in the project, none is a fallback (checked from the node JSON: the text nodes use SF Pro Rounded, Bricolage Grotesque, Instrument Sans and Raleway; Montserrat and SF Pro Text appear only as unused base styles and the Safari toolbar):

- **SF Pro Rounded**: bundled (`src/assets/fonts`, `styles/parent.css`, family `GTH Parent Rounded`), scoped by an attribute on `<html>`. The recruiter chat sets `data-recruiter-ui` through `hooks/useScopedRoundedFont` (the parent screens use the same hook with `data-parent-ui`); the line-height pin (`normal` = 1.19) and the Nunito weight compensation come with it. With the real font the text wraps where Figma wraps.
- **Bricolage Grotesque** (wght + opsz), **Instrument Sans**, **Raleway**: self-hosted from npm (`@fontsource-variable/*`, imported in `src/main.jsx`), no longer from the Google CDN (Bricolage and Instrument Sans were removed from the `index.html` link; Nunito, DM Mono and the serifs still load from it). Tokens `--font-heading`, `--font-ui`, new `--font-raleway` (`index.css`) and the playful stacks name the `Variable` families first. Raleway is used where Figma uses it: the manual-form prompt line (`message.fontFamily = 'raleway'`) and the Min / Max / Frequency captions (`inscriptionClassName` on `TextInput` / `Select`). Verified in the browser: the loaded faces are the self-hosted ones and no request goes to Google for them.

## Accessibility pass (no real screen reader)

A real screen reader was **not** run (none available here). Done instead: axe-core 4.14 (WCAG 2 A/AA, 2.2 AA, best practice) over 19 states at 1440 and 390; the accessibility tree for nameless controls; keyboard probes. Fixed: the hidden file input had no label, the stage trail scroller was not keyboard-reachable, no level-one heading after the hero, content outside landmarks (progress block, Chat | Profile switch), a second `banner` inside the job form, an unnamed month select, and `ui/Modal` had no focus trap (Tab now wraps inside, focus starts in the dialog and returns to the opener on close; Esc already closed). Left, by design: colour contrast of the grey upload size text (Figma `#a1a1a1`, Figma colours win). The confirmation dialog's Esc goes back to the form ("Go back and edit"), as its button does.
