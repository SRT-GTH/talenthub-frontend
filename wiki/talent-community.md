## Code map

- Foundation: `communityState.js` (URL hook), `CommunityFrame.jsx` (talent shell, Community active, `?rail=collapsed`), `communityMembership.js` (join / mute state in sessionStorage; default: Frontend Devs / Software Engineering Ghana joined), `communityData.js` (blocks: browse · page · posts).
- Pages (`src/pages/talentCommunity/`): `CommunityBrowsePage` `/community`, `CommunityPage` `/community/:communityId`, `CommunityPostPage` `/community/:communityId/post/:postId`. `software-engineering-ghana` is an alias of the drawn #Frontend Devs Ghana page; any other catalogue id gets a generated page; unknown ids redirect to `/community`.
- Parts: browse (`CommunityCard`, `CommunityBrowseParts`, `CommunityJoinedMenu`), page (`CommunityPageParts`, `CommunityFeedParts`, `CommunityTabPanels`, `CommunityPostCard`), posts/dialogs (`CommunityDialogs` create / report / leave / milestone, `MilestoneShareModal` — also used by Career Buddy —, `PostComments`, `CommunityPendingParts`).
