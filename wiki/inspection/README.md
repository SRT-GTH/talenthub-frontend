# Screen inspection (all screens, every control, where it leads)

> Generated 2026-11-11 from the route table (`src/App.jsx` and the five portal routers) and the frame tables in this wiki. One phase per file, in user-journey order. Interactive version with saved ticks and notes: https://claude.ai/artifact/2XYzEPjfCCJhBU39gdLTaC

## How to use

1. Start the app (`npm run dev`, http://localhost:5173) and open the phase file.
2. For each screen: open the URL, try every control listed, tick it when it leads to the right place, and tick "Figma ☐" after comparing with the Figma frame. Controls marked ⚠ are the first to look at.
3. "Documented states" are extra URLs of the same screen (dialogs, tabs, empty / error states) from the flow pages of this wiki: open each and compare with Figma.
4. "Shared chrome" (top bar, sidebar, footer controls found on most screens of a phase) is listed once at the top of the phase.
5. A click map ("what it does now") is generated by a script that opens each screen on a production build with no signed-in session, clicks every visible control on a fresh load and records the result. It cannot judge whether the result is the right one: that is your check.
